Create a simple page that uses Google Place Autocomplete to find place and show in map with following
requirements
1. Textbox must be autocomplete action and get result from Google API
(https://developers.google.com/maps/documentation/javascript/examples/places-autocomplete)
2. Must use redux (redux toolkit is allowed) to store result and display all searches that user tries
3. Use one of following Redux middleware in combination with Redux
a. Redux Thunk
b. Redux Promise
c. Redux Saga
d. Redux Observable
4. May choose Bootstrap, Tailwind, Material UI for styling
5. Design a friendly, usable and scalable code structure.
Optional
- Using es6 or above, higher order component pattern / custom hooks / render props pattern, react
hooks, functional component.
- Mark a place as favourite by triggering webservice call to java spring boot API and save in database.
Database can be mysql, mssql (preferred) or equivalent relational database.
